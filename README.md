# 🌸 TaskFlow • Daily Tasks, Separate List Tiles & Habit Alarms

A modern, responsive productivity web application with separate list tiles (Shopping, Work, Visit, Movies, Study, Health, Personal), interactive checklists, item editing (fixing typos/spelling mistakes), and habit tracking with customizable Web Audio alarms.

---

## 🌟 Key Features

- **📂 Separate List Category Tiles**: Dedicated pastel tiles for *Shopping, Work, Visit, Movie, Study, Health, Personal, and All Tasks*.
- **✏️ Edit & Delete Actions**: Quickly fix spelling mistakes, edit titles, update priority levels, and due dates via the Edit Modal.
- **🌱 Daily Habits & Timely Alarms**: Track daily streaks and configure scheduled sound reminders with an in-browser ringing alarm popup modal.
- **🎨 Pastel Glassmorphic UI**: Ambient mesh gradient theme with full Light & Dark mode support.
- **💾 Local Persistence**: All tasks and habits are saved automatically in `localStorage`.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Double-click `index.html` to open directly in any modern web browser (Google Chrome, Edge, Safari, Firefox).
3. No build tools or installations required!
